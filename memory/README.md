# memory/ — 技能记忆目录

> 本目录是 mvp-expert-team 技能的**自携带记忆区**：位于技能根目录（与 SKILL.md 同级），随技能一起存在。
> 每次调用本技能时：**先读 memory/ 下的记忆文件**（加载上次进度与可复用决策），**用后回写**（追加日志 + 更新长期记忆 + 维护项目台账）。

## 结构

```
memory/
├── README.md              # 本说明文件
├── MEMORY.md              # 长期记忆：可复用决策、用户偏好、项目约定（按分段维护，去重追加）
├── project-tracker.md     # 项目进度台账：进行中项目的任务级进度/阶段里程碑/关键裁决 Ruling
├── YYYY-MM-DD.md          # 活跃日志：每次调用当天的记录（追加模式，一行一条）
└── archive/               # 冷归档
    └── YYYY-MM.md         # 月度日报摘要（超过 30 天的日志归档于此）
```

## 使用规则（由 SKILL.md「十一、记忆管理」执行）

1. **调用前（Step 0 加载）**：读 `MEMORY.md` + 今日日志 + `project-tracker.md`，定位延续项目的上次中断点；全新请求跳过。
2. **调用后（回写）**：
   - 追加今日日志条目：`[mvp-expert-team] 场景 → 关键决策`
   - 可复用经验去重写入 `MEMORY.md` 对应分段（每条 1-2 行）
   - 多 Phase 交付时更新 `project-tracker.md`（任务进度/里程碑/裁决）
3. **轮转**：日志早于今天 − 30 天或文件数 > 35 → 归档为 `archive/YYYY-MM.md`；首次归档先确认再删原文。

## 注意

- 记忆与交付同等重要，写入失败必须在回复中明示「记忆未写入」。
- 本目录内容为技能运行记忆，随技能根目录存放；如需跨机同步，随技能仓库整体携带或手动复制。
