# 02 · P0 规则与反 AI 清单（门禁执行手册）

> 本文件是 SKILL.md「P0 绝对规则」的完整执行版。门禁检查、设计评审、代码自查时逐条对照。
> 核心立场：AI 生成产品"一眼假"的头号原因不是功能弱，而是**视觉与文案的模板味**。反 AI 味是工程任务，不是审美偏好。

---

## 一、P0 三条红线（详细定义 + 判定 + 替代）

### P0-1 禁止 emoji 作功能图标（P0 致命）
| 场景 | 判定 | 替代 |
|------|------|------|
| `🚀 快速开始` 等 emoji 作功能图标 | ❌ 退回 | Spec 锁定图标库的对应语义图标（如 Rocket） |
| 多套图标库混用 | ❌ 退回 | 统一到 Spec 锁定的一套 |
| 无框架场景需要图标 | 允许内联 SVG | 必须与锁定图标库描边风格一致（stroke 1.5-2、round 端点） |
| 用户生成内容 / IM 消息 | ✅ 允许 | 仅限这两类 |

图标尺寸规范：16px 行内 / 20px 按钮内 / 24px 独立，全项目一致。

**扫描命令**（对所有 .tsx/.jsx/.vue/.html/.svelte/.css/.md 产出执行）：
```bash
grep -rP '[\x{1F300}-\x{1F9FF}\x{2600}-\x{26FF}\x{2700}-\x{27BF}\x{FE00}-\x{FE0F}\x{1F000}-\x{1F02F}\x{1F0A0}-\x{1F0FF}\x{1F100}-\x{1F64F}\x{1F680}-\x{1F6FF}\x{1F900}-\x{1F9FF}\x{1FA00}-\x{1FA6F}\x{1FA70}-\x{1FAFF}\x{200D}\x{20E3}]' src/
# 预期：零匹配。命中 → 替换为锁定图标库对应图标（🚀→Rocket ✨→Sparkles 📊→BarChart3 🎯→Target 等）
```

### P0-2 禁止紫色→粉色渐变主视觉（P0 致命）
- 判定：`#7C3AED` `#A855F7` `#9333EA` `#EC4899` 之间任意渐变组合；Indigo→Pink 渐变；`from-purple-* to-pink-*` Tailwind 类。
- 允许：Indigo `#6366F1` / Slate Blue `#4F46E5` 作**纯色**；同色系深浅渐变（`#2563EB → #1D4ED8`）。
- 本质红线：三位一体套路 = 渐变 + 发光边框 + 毛玻璃。单一元素出现不算，组合出现即退回。
- 替代方案：纯色背景 + 品牌色光晕（opacity < 0.12），或几何图形装饰。

```bash
# 扫描命令
grep -rn 'purple.*pink\|7C3AED.*A855F7\|7C3AED.*EC4899\|from-purple.*to-pink\|9333EA.*EC4899' src/
```

### P0-3 禁止 AI 模板味（P0 致命）
| 对象 | 判定 | 替代 |
|------|------|------|
| 文案 | "Lorem ipsum" / "Welcome to Our App" / "Sign up today" / "Get started" / "Elevate" / "Seamless" / "Unleash" / "Next-Gen" | 具体动作与价值："3 分钟搭建你的第一个看板"；用具体动词 |
| 颜色 | 硬编码 hex（唯一例外 `#fff` `#000`） | Design Token 引用 `var(--accent)` |
| Hero | 大标题+副标题+居中 CTA+抽象 3D 图形 | 真实产品界面截图 / 可交互 Demo / 具体数据；非对称布局 |
| 动效 | 弹跳缓动 `cubic-bezier(0.68, -0.55, 0.265, 1.55)` | 150ms 收敛 + `cubic-bezier(0.2, 0, 0, 1)` |
| 数据 | "10,000+ 用户信赖""99.9% 正常运行" 无来源整数 | 真实数据；示例数据用有机真实感数字（47.2% 而非 50%） |
| 人物 | "John Doe"/"Sarah Chan" | 有创意的真实感名字 |
| 头像 | 通用蛋形 SVG user 图标 | 创意照片占位或特定样式 |

```bash
# 扫描命令
grep -rn 'Welcome to\|Lorem ipsum\|Sign up today\|Elevate\|Seamless\|Unleash' src/
```

## 二、设计 7 大罪（反 AI 模板 · 完整对照）

| # | 罪 | 特征 | 替代 |
|---|-----|------|------|
| 1 | 紫色渐变综合症 | `linear-gradient(135deg,#7C3AED,#A855F7)` + 发光 + 毛玻璃三位一体 | 纯色 + 光晕 opacity<0.12 / 同色系渐变 |
| 2 | Emoji 替代图标 | 🚀🔥💡✨⚡ 作功能图标 | 锁定图标库，统一色值尺寸 |
| 3 | 千篇一律 Hero | 大标题+副标题+居中 CTA+抽象图形 | 真实产品截图 / 交互 Demo / 非对称 |
| 4 | 默认靛蓝强调 | Tailwind 默认 `#6366f1` 当强调色（业界公认首罪） | 品牌特定色，每屏 ≤2 处 |
| 5 | 圆角卡片+彩色左边框 | `.card { border-radius:12px; border-left:3px solid accent }` | 边框颜色区分：`1px solid var(--border)` + hover 变 accent |
| 6 | 虚构指标 | 无来源的整数大数字 | 真实数据 / 有机数字（47.2%）|
| 7 | 填充式文案 | Welcome to / Sign up today / 空洞修饰 | 具体动作 + 价值 |

## 三、12 条绝对禁令（出现即重写，不可协商）

1. **侧条纹边框**：`border-left/right > 1px` 作卡片彩色强调。
2. **渐变文字**：`background-clip: text` + 渐变。用纯色 + 字重/大小强调。
3. **默认毛玻璃**：装饰性 blur + 玻璃卡片（除非明确功能目的）。
4. **Hero 指标模板**：大数字 + 小标签 + 辅助数据 + 渐变强调（SaaS 套路）。
5. **相同卡片网格**：同尺寸卡片 + 图标 + 标题 + 文字无限重复。→ 2 列 Z 字 / 非对称 / 横滚。
6. **每节小号大写标签**：每个 section 头顶都挂 "ABOUT/PROCESS/PRICING" = AI 语法。
7. **编号 section 标记**：`01·关于 / 02·流程 / 03·定价` = AI 脚手架（真序列才用）。
8. **文字溢出容器**：长标题 + 大 clamp + 窄网格 = 移动端溢出。
9. **幽灵卡片**：1px border 与 box-shadow blur≥16px 同现 → 二选一。
10. **过度圆角**：卡片 ≥24px = 过度圆滑。卡片上限 12-16px。
11. **重复结构动效**：每 section 相同淡入。揭示动画要匹配内容。
12. **奶油/米色默认背景**：warm-neutral 色带当默认。温暖感靠强调色+排版+图传达，不靠背景。

## 四、前端交付视觉检查清单（19 项）

### ⛔ P0 三红线（任一不过 = 立即退回）
- [ ] 图标全部来自锁定图标库，emoji 正则扫描零匹配
- [ ] 无紫色→粉色渐变（含 from-purple to-pink）
- [ ] 无模板味占位 / 空洞文案 / 默认靛蓝强调

### Token 与色彩（6 项）
- [ ] 所有颜色 `var(--token)` 引用，无硬编码 hex（`#fff`/`#000` 除外）
- [ ] `--accent` 每屏 ≤2 处
- [ ] 调色板四层：中性 70-90% / 强调 5-10% / 语义 0-5% / 效果 <1%
- [ ] 无纯黑 `#000` / 纯灰 `#808080` 直出（已加色调）
- [ ] 无 Tailwind 默认靛蓝 `#6366f1` 作强调色
- [ ] 深色模式用亮度递进（`#08090a→#0f1011→#191a1b→#28282c`）而非阴影

### 排版（4 项）
- [ ] Inter + Noto Sans SC + JetBrains Mono（标题/正文/等宽层级明确）
- [ ] ALL CAPS 字距 ≥0.06em
- [ ] 标题 ≥32px 负字距（-0.01~-0.02em）
- [ ] 字重体系 400/510/590（正文/强调/标题）

### 响应式与无障碍（4 项）
- [ ] 移动端适配（断点 640/1024/1280）
- [ ] 触摸目标 ≥44×44px，间距 ≥8px
- [ ] 键盘可达 + `:focus-visible` ring + aria-label
- [ ] 动效支持 `prefers-reduced-motion`

### 状态覆盖（2 项）
- [ ] 核心组件 5 态：Loading/Empty/Error/Populated/Edge
- [ ] 按钮 6 态：Default/Hover/Focus/Active/Disabled/Loading

## 五、代码级 AI 痕迹检测（前端自查 · 确定性规则精华）

### CSS/视觉
| 检测 | 判定 | 修复 |
|------|------|------|
| `border-left/right >1px` 彩色强调 | 侧条纹 | 完整边框/背景色/前导数字图标 |
| `background-clip:text` + 渐变 | 渐变文字 | 纯色 + 字重区分 |
| 装饰性 backdrop-filter blur | 毛玻璃 | 移除或改为功能性半透明 |
| box-shadow 发光/霓虹 | AI 发光 | 内层边框或微妙着色阴影 |
| 纯黑 `#000` 背景/文本 | AI 纯黑 | `#0D1117`/`#111111` 炭黑 |
| 卡片圆角 ≥24px | 过度圆滑 | 12-16px，标签按钮可用 pill |
| 1px border + blur≥16px 阴影同现 | 幽灵卡片 | 二选一 |
| 奶油/米色背景 | 默认暖色 | 品牌色系中性色 / 真 off-white |

### 排版/布局/内容痕迹
| 检测 | 判定 | 修复 |
|------|------|------|
| Inter 当展示字体声称"高级" | 默认字体 | Geist/Outfit/Cabinet Grotesk/Satoshi |
| 标题字距 <-0.04em | 过度紧 | 最低 -0.04em |
| 每 section 上方小写追踪标签 | 脚手架语法 | 单一品牌系统标签 |
| `01·关于` 编号标记 | AI 脚手架 | 真序列才用 |
| 正文行宽 >75ch | 忽略可读性 | 65-75ch |
| 3 个等宽卡片横排 | 三卡套路 | 2 列 Z 字 / 非对称 / 横滚 |
| 卡片内嵌套卡片 | 嵌套卡片 | 分隔线/间距/背景色区分 |
| 每节相同淡入 | 反射动效 | 匹配内容的揭示动画 |
| `h-screen` Hero | 视口错误 | `min-h-[100dvh]` |
| flex 百分比 `w-[calc(33%-1rem)]` | flex 数学 | CSS Grid `grid-cols-3 gap-6` |
| Acme/Nexus/SmartFlow 品牌名 | 创业套路名 | 有上下文的高级品牌名 |

### 动态检测脚本（CI 可接入 · 一次性扫完整项目）

```bash
#!/bin/bash
# ai-trace-scan.sh —— 代码级 AI 痕迹一键检测
# 用法：bash ai-trace-scan.sh src/
# 退出码：0 通过 / 1 发现违规

SRC="${1:-src/}"
FAIL=0

echo "=== [1/5] emoji 作功能图标 ==="
EMOJI=$(grep -rPn '[\x{1F300}-\x{1F9FF}\x{2600}-\x{26FF}\x{2700}-\x{27BF}]' "$SRC" --include='*.tsx' --include='*.jsx' --include='*.vue' --include='*.html' --include='*.svelte' 2>/dev/null)
if [ -n "$EMOJI" ]; then echo "$EMOJI"; FAIL=1; else echo "PASS 无 emoji"; fi

echo "=== [2/5] 紫粉渐变 ==="
PURPLE_PINK=$(grep -rEn 'from-purple-[0-9]+ to-pink-[0-9]+|#7C3AED.*#A855F7|#7C3AED.*#EC4899|9333EA.*EC4899' "$SRC" 2>/dev/null)
if [ -n "$PURPLE_PINK" ]; then echo "$PURPLE_PINK"; FAIL=1; else echo "PASS 无紫粉渐变"; fi

echo "=== [3/5] 圆角 ≥24px（过度圆滑） ==="
ROUND=$(grep -rEn 'rounded-\[2[4-9]px\]|rounded-\[3[0-9]px\]|border-radius:[[:space:]]*[2-9][0-9]px|border-radius:[[:space:]]*[1-9][0-9]{2,}px' "$SRC" 2>/dev/null)
if [ -n "$ROUND" ]; then echo "$ROUND"; echo "（标签按钮可用 pill，主体卡片上限 16px）"; FAIL=1; else echo "PASS 圆角合规"; fi

echo "=== [4/5] Tailwind 默认靛蓝 ==="
INDIGO=$(grep -rEn '#6366f1|#6366F1|bg-indigo-[0-9]+|text-indigo-[0-9]+|border-indigo-[0-9]+' "$SRC" 2>/dev/null)
if [ -n "$INDIGO" ]; then echo "$INDIGO"; echo "（Indigo 作纯色允许，作默认强调色视为首罪）"; FAIL=1; else echo "PASS 未用默认靛蓝"; fi

echo "=== [5/5] 模板味文案 ==="
TEMPLATE=$(grep -rEn 'Welcome to|Lorem ipsum|Sign up today|Get started|Elevate|Seamless|Unleash|Next-Gen' "$SRC" 2>/dev/null)
if [ -n "$TEMPLATE" ]; then echo "$TEMPLATE"; FAIL=1; else echo "PASS 文案具体"; fi

if [ $FAIL -eq 0 ]; then echo "=== ALL PASS ==="; else echo "=== FAIL · 见上方违规项 ==="; fi
exit $FAIL
```

**CI 接入示例**（`.github/workflows/ai-trace.yml`）：
```yaml
name: AI Trace Scan
on: [push, pull_request]
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run scan
        run: bash scripts/ai-trace-scan.sh src/
```

> 进阶：把脚本挂到 git pre-commit hook（`lefthook.yml` 或 `husky`），本地提交前就阻断违规提交。

## 六、工程级设计精规（Token / 排版 / 色彩 / 动效）

### 间距系统（4px 基准网格）
仅允许：`4 8 12 16 20 24 32 40 48 64 80`。禁止 `5 7 13 15 22 30` 非标值。

### 排版精规
| 场景 | 字距 |
|------|------|
| 正文 14-18px | 0 |
| 小字 11-13px | 0.01-0.02em |
| ALL CAPS | 必须 0.06-0.1em |
| 标题 ≥32px | -0.01 ~ -0.02em |
| 展示字 ≥48px | -0.02 ~ -0.03em |

最多 2 种字体配对；正文每行 50-75 字符（中文约 25-37 字）；行高正文 1.5-1.7 / 标题 1.1-1.3。

### 色彩核心规则
1. 每屏最多 2 处可见 `--accent`。
2. Token 按用途命名，不按色相命名（`--accent` 不叫 `--blue`）。
3. 深色主题避免纯黑/纯白直出。
4. 深色层级用亮度递进不用阴影。

### 动效精规
| 场景 | 时长 |
|------|------|
| 即时反馈（按下/开关） | 50-100ms |
| 状态确认（hover/选中） | 150ms（跨系统收敛值） |
| 进入 UI（下拉/Toast） | 200-300ms |
| 跨屏过渡（切页/模态） | 300-500ms |

标准缓动 `cubic-bezier(0.2, 0, 0, 1)`。必须支持 `prefers-reduced-motion`。只动 transform/opacity，不动画 width/height。z-index 语义化（dropdown→sticky→modal-backdrop→modal→toast→tooltip）。

### 认知负荷（设计评审必查）
工作记忆同时 ≤4 项：导航 ≤5 顶级项；表单每组 ≤4 可见字段；主按钮 1 + 次按钮 1-2，其余收菜单；定价 ≤3 档。8+ 项 = 过载。

### 反射拒绝字体/美学列表（训练数据默认值 → 制造同质化）
Fraunces · Newsreader · Lora · Crimson · Playfair Display · Cormorant · Syne · IBM Plex Mono/Sans/Serif · Space Mono · Space Grotesk · DM Sans · Outfit · Plus Jakarta Sans · Instrument Sans/Serif（Inter 可作正文，不得当展示字体声称"高级"）。
编辑排版风（衬线展示 + 斜体 + 小型 mono 标签）2026 已被 AI 工具默认采用，非杂志/编辑类产品不默认走此路线。
